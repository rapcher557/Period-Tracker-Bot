# Period-Tracker-Bot
A simple Telegram bot for tracking and managing menstrual periods, built with Python and python-telegram-bot.


----------------------------------------------------------------

# Telegram Bot ثبت پریودی

یک ربات تلگرامی برای ثبت و مدیریت دوره‌های پریودی که با Python و کتابخانه `python-telegram-bot` توسعه داده شده است.

## امکانات

- ثبت تاریخ پریودی
- ذخیره و مدیریت اطلاعات دوره‌ها
- استفاده از ربات به صورت مستقیم در تلگرام
- رابط کاربری ساده و کاربردی

## نیازمندی‌ها

برای اجرای پروژه به موارد زیر نیاز دارید:

- Python 3.9 یا بالاتر
- python-telegram-bot نسخه 20.0 یا بالاتر
